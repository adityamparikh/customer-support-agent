# Plans: work in progress across sessions

When a task will not finish in one session, write its state here so the next session, human or
agent, can pick it up without rereading the history.

- One file per task: `YYYY-MM-DD-short-name.md`.
- Sections: **Goal**, **Decisions** (what was chosen and why), **Done**, **Left** (concrete next
  steps), **Open questions** (what needs a human).
- Update it before ending a session. When the task is finished, move durable decisions into an
  ADR (`docs/adr/`) or a spec (`docs/specs/`) and delete the plan.
